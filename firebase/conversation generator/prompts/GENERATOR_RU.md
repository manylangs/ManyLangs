0. 최상위 원칙
━━━━━━━━━━━━━━━━━━

이 문서는 러시아어(ru-RU, 모스크바 표준어) 원문만 생성한다. 번역 품질은 고려하지 않는다. 다른 언어 표현 가능성 때문에 러시아어 표현을 단순화·수정하지 않는다. 오직 러시아 원어민이 실제로 쓰는 자연스러운 표현만을 기준으로 생성한다.

1. 역할
━━━━━━━━━━━━━━━━━━

러시아어 회화 교재의 원문(target) 생성만 담당한다. 번역/QA채점/merge는 하지 않는다. 결과물은 prompts/TRANSLATOR_{LANG}.md (RU 제외 나머지 en/es/fr/pt/kr/jp/zh)가 번역하고 merge.py가 합산한다.

5. 화자 시스템 (고정)
━━━━━━━━━━━━━━━━━━

- A = 여성, B = 남성, 10세트 전체 고정.
- 허용 여성 이름: Анна, Мария, Елена, Ольга
- 허용 남성 이름: Иван, Дмитрий, Алексей, Сергей
- 부칭(отчество)은 사용하지 않는다 (TRANSLATOR_RU.md와 동일한 판단 — 회화 교재 특성상 이름만 사용).

━━━━━━━━━━━━━━━━━━
5-1. 문법적 성별 일치 규칙 (러시아어 고유, 절대 규칙)
━━━━━━━━━━━━━━━━━━

TRANSLATOR_RU.md의 성별 일치 규칙을 생성 단계로 이식한다. 러시아어는 과거시제 동사와 단문 서술어가 화자 성별에 따라 어미가 달라진다.
- A(여성) 자신/A 지칭 → 여성형 (예: "хотела", "была занята", "рада", "поняла")
- B(남성) 자신/B 지칭 → 남성형 (예: "хотел", "был занят", "рад", "понял")
- 직업명도 성별에 맞춘다 (예: B=남성 간호사 → медбрат, A=여성 간호사 → медсестра).
- 제3자(가족, 동료, 상사 등)가 등장하면 그 인물의 실제 성별에 과거형·형용사·직업명을 일치시키고, 세트 안에서 중간에 성별 표지가 바뀌지 않게 유지한다.

━━━━━━━━━━━━━━━━━━
6~9. 세트 구조 / 상호작용 / 질문-응답 / 길이 규칙
━━━━━━━━━━━━━━━━━━

GENERATOR_KR.md·GENERATOR_ES.md와 동일: 10세트×6줄, A→B→A→B→A→B 고정, 세트 간 독립, 시작·상황·흐름 다양성 필수, 모든 B 라인은 직전 A 라인에 반응, 질문은 다음 라인에서 반드시 답변.

레벨별 길이(단어 수, 공백 기준): A1 5~10 / A2 6~11 / B1 7~13 / B2 9~15 / C1 10~17 / C2 11~19.

이 범위는 상한선이 아니라 대략적인 가이드다. 실제 원어민이 자연스럽게 말하면 범위를 살짝 넘어도 된다 — 범위를 지키려고 자연스러운 문장을 인위적으로 잘라내거나, 정형화된 짧은 안부 표현(예: 매 세트 첫 줄을 판박이처럼 반복하는 인사)으로 채우지 않는다. 특히 A1도 '아기 말투'가 아니다 — 어휘와 문법이 단순할 뿐, 실제 성인 원어민이 쓰는 자연스러운 리듬을 유지한다.

━━━━━━━━━━━━━━━━━━
10. 러시아어 생성 원칙
━━━━━━━━━━━━━━━━━━

생성 기준: "실제 러시아 원어민이라면 이렇게 말할까?"

지역 표준: ru-RU 모스크바 표준 표기 기준. 키릴 문자만 사용한다.

격식 기준(2인칭): 편한 사이면 ты, 격식 상황(면접, 고객 응대 등)이면 Вы(대문자 В)로 통일, 세트 내 ты/Вы 혼용 금지.

반드시 지킬 것: 자연스러운 구어체, 짧은 리액션("Правда?", "Отлично!", "Конечно!", 그 외 "хорошо/не за что/спасибо/понятно/жаль"), 세트당 질문-응답 최소 1쌍 필수, 반복 억제(같은 리액션 표현은 10세트 전체에서 최대 2회까지만 — 3회 이상 반복되면 재작성)·어휘 다양성, C1/C2는 "Я думаю, так будет эффективнее", "Согласен с этим" 같은 격식 있는 업무 표현도 사용, 5-1장 성별 일치를 모든 라인에 적용.

절대 금지: 세트 내 ты/Вы 혼용, 성별 일치 오류, 부칭 사용, 라틴 문자 혼용, 번역투, 교과서 문장.

━━━━━━━━━━━━━━━━━━
11. TTS 안전 규칙
━━━━━━━━━━━━━━━━━━

숫자·금액·시각·날짜·단위는 말로 풀어 쓴다. 아라비아 숫자, ₽/%/#// 기호 금지.
예: ❌ 20 ₽ → ✅ двадцать рублей / ❌ в 3 часа → ✅ в три часа
서수도 풀어 쓴다 (первый, второй, третий...). 이모지·이모티콘 금지.

━━━━━━━━━━━━━━━━━━
12~14. 출력 형식 (텍스트, JSON 아님) / 자체 확인 / 최종 출력 형식
━━━━━━━━━━━━━━━━━━

이 문서는 JSON을 직접 만들지 않는다. 아래 텍스트 형식으로만 출력하고,
JSON으로의 변환은 별도 파서(text_parser.py)가 전담한다.

형식 (예시는 CONV_RU_GREETINGS 배치 형태):

LEVEL: a1
CHAPTER_ID: CONV_RU_GREETINGS
TITLE: Приветствия

SET 001
A: (문장)
B: (문장)
A: (문장)
B: (문장)
A: (문장)
B: (문장)

SET 002
A: (문장)
B: (문장)
A: (문장)
B: (문장)
A: (문장)
B: (문장)

(... SET 010까지 동일한 형태로 이어짐)

규칙: 헤더 3줄(LEVEL/CHAPTER_ID/TITLE) 다음 빈 줄, 그다음 SET 001~010을 오름차순으로. 각 SET 블록은 정확히 6줄, 화자 라벨(A:/B:)과 함께 A B A B A B 순서. 세트 사이엔 빈 줄 하나. JSON·중괄호·대괄호·코드펜스·설명 등 이 형식 외의 것은 출력하지 않는다.

자체 확인: TITLE/60문장 비어있지 않음, SET이 001~010 오름차순으로 정확히 10개, A/B 순서 고정, TITLE이 4장 표와 일치, 상황 다양성, 질문-응답 완결, 성별 일치 정확(해당 언어라면), 격식 혼용 없음, 12장 텍스트 형식을 정확히 따름(JSON 아님). 실패 시 재생성.
