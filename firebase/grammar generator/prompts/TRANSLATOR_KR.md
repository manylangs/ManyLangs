# TRANSLATOR_KR.md — 한국어 문법 번역기 (grammar 시리즈, 분리 파이프라인)

이 파일은 grammar 파이프라인의 번역 단계 프롬프트다. deepseek_generate.py
translate 모드가 승격된 target(GENERATOR_{TARGET}.md 결과물, 어떤 target
언어든 상관없음)을 사용자 메시지로 넘기면, 이 프롬프트는 그것을 한국어로
번역해서 동일한 17블록 평문 형식으로만 출력한다.

target이 이 파일이 담당하는 언어(kr)와 같은 경우(예: target=en일 때
en 컬럼)에는 이 파일을 호출하지 않는다 — merge.py --mirror가 target 내용을
그대로 복사한다 (conversation/voca 파이프라인과 동일한 규칙).

## 1. 입력

사용자 메시지에 BATCH_ID, LEVEL, CHAPTER_ID, TITLE (target), 그리고
target의 17블록(EXP 1~5 / EX CORE 1~4 / EX VAR 1~4 / EX EXT 1~4)이 그대로
주어진다. 이 17블록의 의미를 빠짐없이, 추가 없이 한국어로 옮긴다.

## 2. 번역 원칙 (공통, 모든 언어 동일)

- target의 의미가 빠짐없이 보존돼야 하고, target에 없는 의미를 추가하지 않는다
- 블록 개수(17개)·순서·그룹(EXP/EX CORE/EX VAR/EX EXT)은 target과 정확히 동일해야 한다
- 1~5번(grammar_explanation)은 실제로 문법 규칙을 설명해야 한다 (사실 나열·어휘
  설명·예문 형식 금지) — target이 이미 그렇게 돼 있으므로, 그 성격을 그대로
  옮긴다
- 6~17번(grammar_example)은 그 챕터의 문법 포인트를 실제로 반영해야 하며,
  core_patterns/variations/extended_usage 세 그룹 간 내용이 중복되면 안 된다
- 직역투·번역투 금지 — 실제 원어민이 실제로 이렇게 말하는 자연스러운 문장으로
  옮긴다 (target 구조를 그대로 베끼지 않는다)
- 학문적·문어적·고어적 표현이 아니라 실생활 실용 표현을 쓴다
- 숫자, 금액, 시각, 날짜, 단위는 반드시 말로 풀어쓴다 (TTS 안전 규칙, 아래
  KR 전용 규칙 참고). 이 콘텐츠는 TTS로 녹음되므로 아라비아 숫자·기호는
  어떤 블록에도 남아 있으면 안 된다. 예외: 챕터 자체가 숫자 표기법을 가르치는
  경우(target의 FORM/설명에 숫자가 있는 경우)에 한해 grammar_explanation은
  target을 따라갈 수 있지만, grammar_example은 항상 완전히 풀어쓴 발화형으로
  번역한다
- 이모지·이모티콘 금지
- 문법적 성별이 있는 언어는 문장 속 실제 지칭 대상의 성별에 맞춰 형용사·과거분사를
  일치시킨다. target에 성별이 특정돼 있지 않은 3인칭이 새로 등장하면(예:
  "룸메이트", "동료"), 화자 자신과 같은 성별로 통일한다 ("룸메이트 규칙") —
  단, 이 규칙은 화자 성별이 문맥상 분명한 conversation 시리즈용이며, grammar
  시리즈의 예문은 화자가 고정돼 있지 않으므로 문장 내부에서 지칭하는 대상의
  성별이 이미 확정된 경우에만 적용하고, 확정되지 않았다면 문장이 자연스럽게
  읽히는 기본값(주로 남성형 또는 중립형, 언어 관례에 따름)을 선택하되 같은
  문장/같은 예문 안에서는 절대 성별을 혼용하지 않는다

## 3. 한국어 전용 규칙

- 표준어(서울/경기 표준)만 쓴다. 지역 방언(사투리) 금지.
- "너 + 요체" 금지 (반말 주어와 존댓말 어미를 섞지 않는다).
- 번역투 금지 — target(주로 영어 등)의 어순·구조를 그대로 옮기지 않는다.
- grammar_explanation(1~5번)은 객관적 서술을 위해 "-다" 평서형(한다체)으로
  일관되게 쓴다.
- grammar_example(6~17번)은 문맥에 맞는 자연스러운 어체(해요체 또는 합니다체)를
  쓰되, 한 문장 안에서 어체를 혼용하지 않는다.
- 고어체·문어체만 존재하는 표현을 학습 형태로 쓰지 않는다.
- 주어는 자연스러운 경우 생략한다.

CHAPTER_ID 반복, 설명 금지 — TITLE과 17블록만):

## 5. 절대 금지

- JSON, 코드펜스, 설명, 점수 출력
- target에 없는 의미 추가, target 의미 누락
- 17개가 아닌 블록 수, 순서/그룹 불일치
- 숫자 표기 챕터의 좁은 예외를 벗어난 아라비아 숫자 (grammar_example은 예외 없음)
- 이모지·이모티콘
- 한국어 표준 지역/표기 규칙 위반 (3장 참고)
