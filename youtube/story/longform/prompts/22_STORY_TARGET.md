# 22_STORY_TARGET.md — 연속 스토리 target 세트 생성 매뉴얼 v1.2

## 1. 역할
21_STORY_PLANNER.md가 만든 scene_plan을 입력받아, target_lang 대사를
씬 001부터 020까지 순서대로 하나씩 생성한다. 01/09_TARGET_GENERATOR.md의
문장 자연화/TTS 규칙(원어민 자연화, 직역투 금지, 아라비아 숫자 금지 등)을
그대로 따르되, 여기서는 세트 하나가 아니라 이어지는 이야기의 한 조각을
만든다는 점이 다르다.

## 2. 입력 (매 씬 호출마다)
- EPISODE_ID, TARGET_LANG, LEVEL
- SCENE_PLAN 전체 (20개, 참고용 — monologue 필드 포함)
- CURRENT_SCENE_ID, CURRENT_SCENE_MONOLOGUE: 지금 생성할 씬 번호와 독백 여부
- PRIOR_SCENES: 001 ~ (현재-1)번 씬의 target 원문 전체 (요약 아님, 원문 그대로)

## 3. 연속성 규칙
- 주인공 A는 매 씬 동일 인물 — 이름/성격/말투 재설정 금지
- 대화 비트의 B는 이번 씬에서 처음 등장하는 새 인물 — PRIOR_SCENES의 B와 무관
- A는 항상 주인공 관점의 행동/감정을 말한다. 당황·요청·반응·생각은
  전부 A의 몫이다. 대화 비트에서 B에게 그 역할을 넘기지 않는다
  (예: 지갑을 잃어버려 당황하는 사람은 항상 A, 그걸 안내/응대하는
  쪽이 B — 반대로 뒤바뀌면 안 됨)
- 이전 씬에서 끝난 상태(장소, 감정, 미해결 문제)를 이번 씬 시작에 자연스럽게 반영

### 3-1. 돌발 슬롯(surprise=true) 규칙 — 반드시 지킬 것

**이 씬 안에서 절대 문제를 해결하지 마라.** 문제를 만들거나 언급만 하고
끝내라. "찾았다", "됐다", "다행이다", "해결됐다", "여기 있네요(돌려받는
대사)" 같은 완결/해소 표현은 이 씬에 절대 쓰지 않는다. 해소는 이후
다른 씬(대부분 scene_plan에 이미 배치돼 있음)에서 처리된다 — 그건
이 씬이 아니라 다음 씬 생성 때의 몫이다.

**이미 나온 사건과 같은 종류를 반복하지 마라.** PRIOR_SCENES를 훑어서
분실물/지각/길찾기 실패 같은 사건 유형이 이미 나왔다면, 이번 돌발
사건은 다른 종류(예: 우연한 만남, 착각, 작은 실수, 날씨 변화 등)로
만들어라. 같은 유형이 두 번 나오면 잘못된 출력이다.

- 돌발로 생긴 문제가 있다면 PRIOR_SCENES에 명시적으로 남아있으므로,
  자연스러운 타이밍에 해소 — 강제 언급하지 않는다

## 4. 독백 씬 생성 규칙 (monologue: true인 씬)

- 이 씬의 sets[scene_id]에는 A 혼자만의 대사 line_count개를 채운다.
  B는 등장하지 않는다 (다른 인물의 대사를 넣지 않는다)
- 실제 혼잣말/속마음처럼 자연스럽게 — 인사말이나 대화체 어미가 아니라
  독백체(감탄, 관찰, 생각)로 작성
- 예: "우와, 이 영화관 진짜 크다." / "저 사람 표를 잃어버렸나 봐, 안됐다."
  같은 자기 반응/관찰 문장
- line_count가 홀수여도 무방 (A-B로 끝나야 한다는 제약 없음)
- 이 씬은 TTS에서 A 목소리로만 이어서 재생된다

## 5. 대화 씬 대사 규칙 (monologue: false인 씬)
- scene_plan의 line_count 그대로 따름 (가변, 짝수, A-B-A-B... 순서로 끝)
- 기존 01/09 매뉴얼의 자연화·TTS 규칙 동일 적용

## 6. 출력 스키마 (씬 1개)

대화 씬:
{
  "scene_id": "005",
  "title": "",
  "b_gender": "",
  "sets": {
    "005": ["...", "...", "...", "...", "...", "..."]
  }
}

독백 씬 (b_gender 생략):
{
  "scene_id": "013",
  "title": "",
  "sets": {
    "013": ["...", "...", "..."]
  }
}

**title은 반드시 채워라. 빈 문자열이면 잘못된 출력이다.**

## 7. 자체 확인 (self-check)
- title이 비어있지 않은지 확인
- sets 줄수가 scene_plan의 line_count와 일치
- 빈 문장 없음
- 아라비아 숫자/기호 없음 (TTS 규칙)
- A 재소개 문구 없음 (예: "저는 A입니다" 반복 금지, 씬 001 제외)
- surprise=false 씬은 scene_plan의 situation/problem에서 벗어나지 않음
- monologue=true 씬에 B 대사가 섞여 있지 않은지 확인
- monologue=false 씬에서 A가 항상 주인공 관점(당황/요청/반응)을
  맡고 있는지, B가 그 역할을 대신하고 있지 않은지 확인
- surprise=true 씬: 완결/해소 표현이 들어있지 않은지, PRIOR_SCENES에
  이미 나온 사건 유형과 겹치지 않는지 확인
